安装与权限

三步装好 aPaste。

选择与你的 Mac 匹配的安装包，处理 Gatekeeper 提示，再按需授予辅助功能权限。

  1. 01

    下载对应芯片的 DMG

    Apple Silicon 使用 -arm64，Intel 使用 -x86_64。不确定时打开苹果菜单 →「关于本机」查看芯片；Homebrew 会自动选择正确架构。

    brew tap alliottech/tap brew install --cask alliottech/tap/apaste
  2. 02

    移除隔离标记

    把 aPaste.app 拖进「应用程序」后，macOS 可能提示“已损坏，无法打开”。安装包并未损坏；应用尚未经过 Apple 公证，Gatekeeper 因此拦截。

    xattr -dr com.apple.quarantine /Applications/aPaste.app
  3. 03

    授予辅助功能权限

    直接粘贴回原 App 需要在「系统设置 → 隐私与安全性 → 辅助功能」中启用 aPaste。不授权时，记录、搜索、Pinboard 和复制到剪贴板仍可正常使用。
